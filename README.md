# payever Payments for Odoo

This `main` branch keeps **both** Odoo ports:

| Folder | Odoo series | Module version |
|---|---|---|
| `17/payment_payever_official` | Odoo 17 | 17.0.1.0.2 |
| `19/payment_payever_official` | Odoo 19 | 19.0.1.0.2 |

Install and publish from the series branches, which contain only that port at the repo root (Odoo Apps expects this layout):

- [`17.0`](https://github.com/payeverworldwide/payever-odoo/tree/17.0)
- [`19.0`](https://github.com/payeverworldwide/payever-odoo/tree/19.0)

Copy the `payment_payever_official` folder from `17/` or `19/` into your Odoo add-ons directory, then install **payever Checkout**.
